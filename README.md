# globnotes

A self-hosted, database-less note-taking web app where **a note's title is its path** — built for Obsidian vaults and nested markdown trees.

globnotes is a fork of [flatnotes](https://github.com/dullage/flatnotes) by Adam Dullage, with one semantic change: notes can live in subdirectories, and a note's title is its relative path (`dad/recipes/soup` ↔ `dad/recipes/soup.md`).

Full documentation lands with v0.1.0.
